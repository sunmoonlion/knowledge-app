# Dev → Prod k8s 转换流程

## 仓库结构

```
knowledge-app/
├── k8s-scaffold/           ← 脚手架（本文档的核心工具）
│   ├── scaffold.sh         ← 一键生成 k8s 部署目录
│   └── knowledge/                ← 模板文件（无需手动修改）
└── dev-to-prod-deploy/     ← 本目录：方法论文档

k8s/app-platform/<project>/<app>/   ← scaffold 生成目标（独立仓库）
├── resources/k8s-resource/
│   ├── templates/          ← YAML 模板（生成后手工填 key 列表）
│   └── custom-values/      ← conf 和 generate 脚本（生成后手工填值）
└── deploy-<app>/           ← 部署脚本（生成后填 conf）
```

---

## 第一步：用 scaffold 生成目录结构

```bash
cd knowledge-app/k8s-scaffold/

# 后端服务（NestJS / FastAPI）
./scaffold.sh report-service 8000

# Next.js 前端（有 Node.js 服务层）
./scaffold.sh web-frontend 3000 --type node-frontend

# Vite/React 纯静态前端（nginx 托管）
./scaffold.sh admin-frontend 80 --type static-frontend

# 指定输出目录（默认当前目录）
./scaffold.sh report-service 8000 --output-dir /path/to/k8s/project/
```

scaffold 结束时会打印 **必须手工填写的文件清单**，按清单逐一完成。

## 第二步：手工填写（scaffold 生成后的必做工作）

### 2a. ConfigMap 相关（非敏感配置）

**① `templates/configMap/<app>-config.yaml`**

添加实际 key 列表：

```yaml
data:
  NODE_ENV: "${NODE_ENV}"
  REDIS_HOST: "${REDIS_HOST}"
  CASDOOR_ENDPOINT: "${CASDOOR_ENDPOINT}"
```

**② `custom-values/configMap/<app>-config/.../generate-<app>-config.conf`**

填写每个 key 的实际值（k8s 内部 DNS、生产地址等）：

```bash
NODE_ENV="${NODE_ENV:-production}"
REDIS_HOST="${REDIS_HOST:-redis-sunmoonai.data-platform-dev.svc.cluster.local}"
CASDOOR_ENDPOINT="${CASDOOR_ENDPOINT:-https://casdoor.sunmoonai.com}"
```

**③ `custom-values/configMap/<app>-config/.../generate-<app>-config.sh`**

在 TODO 注释下添加 export 语句（每个 key 一行）：

```bash
export NODE_ENV="${NODE_ENV:-}"
export REDIS_HOST="${REDIS_HOST:-}"
export CASDOOR_ENDPOINT="${CASDOOR_ENDPOINT:-}"
```

### 2b. Secret 相关（敏感凭据）

**④ `templates/secret/<app>-secret.yaml`**

添加实际 key 列表：

```yaml
stringData:
  DATABASE_URL: "${DATABASE_URL}"
  REDIS_PASSWORD: "${REDIS_PASSWORD}"
  CASDOOR_CLIENT_SECRET: "${CASDOOR_CLIENT_SECRET}"
```

**⑤ `custom-values/secret/<app>-secret/.../generate-<app>-secret.conf`**

填写真实密钥值：

```bash
DATABASE_URL="${DATABASE_URL:-postgresql://user:password@postgresql.svc:5432/dbname}"
REDIS_PASSWORD="${REDIS_PASSWORD:-realpassword}"
CASDOOR_CLIENT_SECRET="${CASDOOR_CLIENT_SECRET:-realsecret}"
```

**⑥ `custom-values/secret/<app>-secret/.../generate-<app>-secret.sh`**

在 TODO 注释下添加 export 语句：

```bash
export DATABASE_URL="${DATABASE_URL:-}"
export REDIS_PASSWORD="${REDIS_PASSWORD:-}"
export CASDOOR_CLIENT_SECRET="${CASDOOR_CLIENT_SECRET:-}"
```

### 2c. Harbor Registry Secret

**⑦ `custom-values/secret/harbor-registry-secret/.../generate-harbor-registry-secret.conf`**

```bash
DOCKER_SERVER="harbor.sunmoonai.com:30443"
DOCKER_USERNAME="admin"
DOCKER_PASSWORD="realpassword"
```

### 2d. Ingress

**⑧ `templates/ingress/ingress.yaml`**

修改 `Host` 域名和 `PathPrefix`（/api 用于后端，/ 用于前端）。

**⑨ `custom-values/ingress/.../generate-ingress.conf`**

```bash
UNIFIED_HOST="api.myapp.sunmoonai.com"
NODE_IP="101.126.151.0"
SERVICE_NAME="report-service"
SERVICE_PORT="8000"
```

### 2e. 部署配置

**⑩ `deploy-<app>/app/deploy-app/deploy-<app>.conf`**

```bash
REPORT_SERVICE_PROJECT_ID="sunmoonai"
REPORT_SERVICE_NAMESPACE="app-platform-dev"
ENVIRONMENT="development"
```

## 第三步：构建并推送镜像

```bash
cd <app-source-repo>/mybuild/
./push-image.sh --tag 1.0.0
```

更新 `generate-app.conf` 中的 `IMAGE_TAG`（或通过环境变量传入）：

```bash
REPORT_SERVICE_TAG=1.0.0 ./deploy-report-service.sh deploy
```

---

## 第四步：部署

在有 kubectl 权限的机器上执行：

```bash
cd k8s/app-platform/<project>/<app>/deploy-<app>/app/deploy-app/
./deploy-<app>.sh deploy <project_id> <namespace> <environment>

# 示例
./deploy-report-service.sh deploy sunmoonai app-platform-dev development
```

脚本自动完成：Namespace → Secret → ConfigMap → Ingress → PVC → Deployment/Service

## 不同应用类型的注意事项

### 纯静态前端（`--type static-frontend`）

- scaffold 自动禁用 ConfigMap（无运行时 env）
- VITE_* 变量已在构建时烧入 JS bundle，无法运行时修改
- Deployment 无 envFrom 节

### Next.js 前端（`--type node-frontend`）

- 保留 ConfigMap + Secret（Node.js 进程运行时读取）
- ConfigMap：Casdoor 配置等非敏感项
- Secret：CLIENT_SECRET、REDIS_URL

### 后端服务（FastAPI / NestJS）

- ConfigMap：REDIS_HOST、CASDOOR_ENDPOINT 等
- Secret：DATABASE_URL（含密码）、REDIS_PASSWORD、REDIS_URI、CASDOOR_CLIENT_SECRET

## 首次部署检查清单

- [ ] scaffold 生成的所有 TODO 文件已填写完整
- [ ] conf 中无 localhost、无 development 模式（已替换为生产地址）
- [ ] IMAGE_TAG 与 Harbor 最新推送一致
- [ ] Harbor imagePullSecret 已在目标 namespace 部署
- [ ] 目标 namespace 已存在（或 deploy 脚本会自动创建）

## 后续发版

- [ ] 新镜像已推送：`./push-image.sh --tag <new-tag>`
- [ ] 更新 `generate-app.conf` 中的 TAG（或环境变量传入）
- [ ] 如有新增环境变量：同步更新 YAML 模板 + conf + generate.sh
- [ ] 执行 `./deploy-<app>.sh deploy`
